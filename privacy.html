Privacy Policy — Web_Automatic

Last updated: 2026-10-26

What data is accessed

With the user's consent, Web_Automatic accesses the user's own Gmail messages (read, mark as read) and Google Calendar events through Google APIs (scopes: gmail.modify, calendar.events).

How data is used

The data is processed only on the user's own computer to display summaries in a local dashboard. It is not sold, shared, or transferred to third parties, and not used for advertising.

Storage

OAuth tokens are stored encrypted on the user's computer (Windows DPAPI). No Google user data is stored on any external server operated by this app.

Limited Use

Web_Automatic's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke access at any time at https://myaccount.google.com/permissions.
